## 🌟 Key Features

* **Dark / Light Mode Toggle:** Smooth theme switching using custom CSS variables and JavaScript state control.
* **Scroll Animations:** Interactive progress bar and smooth scroll triggers powered by **GSAP** and **ScrollTrigger**.
* **Responsive Layout:** Mobile-first, fully adaptable UI designed with CSS Flexbox & Grid.
* **Working Contact Form:** Integrated with **Formspree** for direct message handling without a backend server.
* **Interactive UI:** Dynamic document title changes on tab focus/blur, custom scrollbar styling, and smooth section transitions.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Animation & Effects:** GSAP (GreenSock Animation Platform), ScrollTrigger
* **Icons & Fonts:** FontAwesome 6, Google Fonts
* **Form Backend:** Formspree API
* **Deployment:** GitHub Pages
